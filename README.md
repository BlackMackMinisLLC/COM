# CoM: Chronicles of Myth website

Public GitHub Pages website for **comtabletop.com**.

## Publishing
Upload the contents of this folder directly to the root of the `COM` repository. The included `CNAME` file points GitHub Pages to `comtabletop.com`.

## Public-content boundary
This website is intended for lore, public previews, product descriptions, news, downloads, and community information. Do not publish the complete Core Rulebook, character creation rules, full statistics, Game Master rules, full bestiary, or other paid product content.
