# COM Website v2

Public-facing site for COM: Chronicles of Myth.

## Paid-rulebook boundary
The complete Core Rulebook is intentionally not included. Keep full creation rules, expertise trees, Chronikin stat blocks, battle techniques, combat chapters, bestiary, gear tables, and GM material inside purchased products unless deliberately released.

## Upload
Upload every file and the assets folder to the repository root. In GitHub: Settings > Pages > Deploy from a branch > main > /(root).

## Replace before launch
Search for `hello@example.com`, `Coming Soon`, `href="#"`, and `yourdomain.com`.
