# Chronicles of Myth Website

Static website for **Chronicles of Myth**.

Upload all files in this directory to the root of the GitHub Pages repository. The custom domain is configured through `CNAME`.

## Mailing-list form
The homepage uses Brevo's hosted iframe. Its height is deliberately set large enough to display the complete form without an internal scrollbar. Keep the existing `assets` directory when deploying these files.

Homepage refinement update:
- Hero background now uses assets/chronicles-tabletop.jpg.
- Homepage Archivist's Note signup banner has been tightened and remains responsive.

Mailing-list signup is hosted on `join-the-archive.html` using the Brevo iframe.
